# MediaCare

Веб-приложение для учёта заявок на техническое обслуживание мультимедийного оборудования (проекторы, аудиосистемы, LED-экраны, микшерные пульты и т. д.).

Дипломный проект по специальности 09.02.07 «Информационные системы и программирование», Омский колледж отраслевых технологий строительства и транспорта, 2026.

## Зачем это нужно

Сервисные компании и IT-отделы часто принимают заявки через таблицы, переписку и бумажные журналы. Из-за этого заявки теряются, а клиент не видит, на каком этапе его обращение. MediaCare собирает все заявки в одном месте: пользователь создаёт заявку и следит за её статусом, администратор обрабатывает заявки и оставляет комментарии.

## Возможности

**Для пользователя**
- регистрация и вход в систему;
- создание заявки: тип оборудования, модель, описание проблемы, приоритет;
- личный кабинет «Мои заявки» со статусами и комментариями администратора.

**Для администратора**
- панель со статистикой: всего заявок, новые, в работе, выполненные, количество пользователей;
- управление заявками: смена статуса (Новая, В работе, Выполнена, Отклонена) и комментарий;
- управление пользователями: смена роли и удаление учётных записей.

## Архитектура

Приложение построено по трёхуровневой клиент-серверной схеме:

1. **Клиент** — HTML-страницы и CSS в браузере: отображение интерфейса, формы, отправка запросов.
2. **Сервер** — PHP на Apache: маршрутизация, авторизация, обработка форм, формирование HTML.
3. **База данных** — MySQL: хранение пользователей и заявок, обращение через PDO с подготовленными запросами.

Маршрутизация сделана без сторонних библиотек: `index.php` смотрит на параметр `page` в адресе (например, `?page=my_tickets`) и подключает нужный файл из папки `pages/`. Формы отправляют данные в отдельные скрипты из `actions/`.

## Безопасность

- пароли хранятся в виде хеша (`password_hash` / `password_verify`, bcrypt);
- запросы к БД выполняются через PDO с подготовленными выражениями, что защищает от SQL-инъекций;
- доступ к административным страницам проверяется функцией `requireAdmin()`;
- при выходе сессия уничтожается (`session_destroy()`).

## Установка и запуск

1. Установите [XAMPP](https://www.apachefriends.org/) или OpenServer (нужны Apache, PHP и MySQL).
2. Скопируйте проект в папку `htdocs` (для XAMPP) под именем **`mediacare`**. В коде используются пути вида `/mediacare/index.php`, поэтому название папки важно.
3. Запустите Apache и MySQL.
4. Откройте phpMyAdmin и создайте базу данных `mediacare_db` (кодировка `utf8mb4`).
5. Выполните SQL-скрипт из раздела ниже, чтобы создать таблицы.
6. При необходимости поправьте параметры подключения в `config/database.php` (по умолчанию: хост `localhost`, пользователь `root`, пароль пустой).
7. Откройте в браузере `http://localhost/mediacare/index.php`.

### Структура базы данных

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role ENUM('user', 'admin') NOT NULL DEFAULT 'user',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
) CHARACTER SET utf8mb4;

CREATE TABLE tickets (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    equipment_type VARCHAR(100) NOT NULL,
    equipment VARCHAR(255) NOT NULL,
    description TEXT NOT NULL,
    priority ENUM('Низкий', 'Средний', 'Высокий') NOT NULL DEFAULT 'Средний',
    status ENUM('Новая', 'В работе', 'Выполнена', 'Отклонена') NOT NULL DEFAULT 'Новая',
    admin_comment TEXT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) CHARACTER SET utf8mb4;
```

### Первый администратор

Новые пользователи регистрируются с ролью `user`. Чтобы получить доступ к админ-панели, зарегистрируйтесь через сайт, а затем выполните в phpMyAdmin:

```sql
UPDATE users SET role = 'admin' WHERE email = 'ваш_email@example.com';
```

После этого администратор может менять роли других пользователей прямо в интерфейсе.
